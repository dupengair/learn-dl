# 04 权重初始值与各层激活值直方图分析

对应脚本:`test04-2_weight-init-activate.py`。

## 脚本做了什么

构造一个 5 层隐藏层(每层 100 个神经元)的前向传播:输入 1000×100 的标准高斯随机数据,逐层做 `z = x·w` 的加权求和,再过 sigmoid 激活,把每一层的激活值(1000×100 矩阵)存进 `activations[i]`,最后画出每层激活值的直方图(1 行 5 列子图)。

权重初始值有三档,靠注释切换:

```python
# w = np.random.randn(node_num, node_num) * 1      # 标准差 1
# w = np.random.randn(node_num, node_num) * 0.01   # 标准差 0.01
w = np.random.randn(node_num, node_num) / np.sqrt(node_num)  # Xavier 初始值,标准差 0.1
```

## 直方图的横轴与纵轴

关键一行是 `plt.hist(a.flatten(), 30, range=(0,1))`:

- **横轴:激活值本身**,即 sigmoid 的输出,取值范围 (0, 1),由 `range=(0,1)` 固定切成 30 个小区间(bin),每个 bin 宽 1/30。
- **纵轴:频数**,即该层全部激活值(1000 个数据 × 100 个神经元 = 10 万个,`flatten()` 拉平)中落在对应横轴小区间里的个数。

所以每张子图回答的问题是:**这一层的 10 万个激活值,都分布在 (0,1) 的哪些位置?** 直方图的"形状宽窄"反映的正是该层神经元输出的多样性(表现力)。

## 两种权重初始值下的直方图差异

### std = 1:两端集中的"双峰"分布

激活值大量堆积在 0 和 1 附近,中间 (0.3~0.7) 几乎是空的,且**越往深层堆积越极端**(第 5 层实测:<0.01 的占 25.3%,>0.99 的占 20.8%,0.4~0.6 区间仅占 4.8%)。

原因:z 的每个分量是 100 个 `x_j·w_j` 之和,x、w 各分量独立且方差均为 1,故 Var(z) = 100,即 z ~ N(0, 10²)。sigmoid 在 |z| ≳ 5 时输出就几乎恒为 0 或 1——**绝大部分神经元工作在饱和区**。

### std = 0.01:挤在 0.5 附近的"窄条"分布

激活值几乎全部落在 0.5 附近极窄的范围内(第 5 层实测:100% 落在 0.4~0.6,标准差仅 0.013),直方图只剩中间一根柱。

原因:此时 Var(z) = 100 × 0.01² = 0.01,即 z ~ N(0, 0.1²)。z 都接近 0,而 sigmoid 在 0 附近近似线性:`sigmoid(z) ≈ 0.5 + z/4`,所以激活值被压在 0.5 ± 0.025 左右的窄带里。

### 差异对照

| | std = 1 | std = 0.01 |
|---|---|---|
| 直方图形状 | 双峰,堆积在 0 和 1 两端 | 单根窄柱,挤在 0.5 附近 |
| 神经元工作区域 | 饱和区 | 0 附近的线性区 |
| 随层数加深 | 两端堆积越来越极端 | 窄带略微变宽但依然极度集中 |

## 这差异体现的结论

两种初始值代表了两类典型的失败模式,**好的权重初始值应当让各层激活值保持适度的广度**:

1. **std = 1 → 梯度消失**:激活值趋向 0/1 意味着 sigmoid 进入饱和区,其导数 `y(1-y)` 趋近 0。反向传播时梯度每过一层都要乘上这个近乎为 0 的导数,层数越深梯度越小,学习停滞。
2. **std = 0.01 → 表现力受限**:各层 10 万个激活值几乎一模一样,意味着各神经元输出无差异——100 个神经元近似等效于 1 个,网络的多样性/容量被浪费;对称地,反向传播时各权重收到的梯度也近乎相同,权重难以学到有区分度的表示。
3. **出路就是脚本当前生效的 Xavier 初始值**(std = 1/√n,n 为前一层节点数,此处 1/√100 = 0.1):它让 Var(z) ≈ 1,实测第 5 层激活值呈现适度宽广、居中偏 0.5 的分布(0.4~0.6 占 57%,标准差 0.116),既不饱和也不塌缩。这是第 6 章"权重初始值"主题的直观演示。
4. 补充:Xavier 初始值适用于 sigmoid/tanh 等对称激活;若激活函数换成 ReLU,依据同样的方差分析应改用 He 初始值(std = √(2/n)),书中随后即有对应实验。

## 补充:为什么偏向 0/1 会导致梯度消失——是导数算出来的,不是看出来的

**先直接回答:这个结论是从反向传播的导数计算推导出来的,直方图本身看不出梯度。** 直方图画的是**前向传播**的激活值,里面根本没有梯度信息。它提供的是推理的**前提**(大量神经元输出在 0/1 附近,即工作在饱和区);结论(梯度消失)要靠 sigmoid 的导数公式加链式法则一步步算出来。

### 推理链

**第一步:反向传播过一层,梯度就要乘一次这一层的"局部梯度"(导数)。** 这是链式法则的要求,对应到代码就是 `common/layer.py` 里 `Sigmoid.backward` 的一行:

```python
def backward(self, dout):
    dx = dout * (1.0 - self.out) * self.out   # dout × y(1-y),y 是前向保存的输出
    return dx
```

上游传来的梯度 `dout`,每穿过一个 sigmoid 层就被乘上 `y(1-y)`。

**第二步:sigmoid 的导数 y(1-y) 在 y 偏向 0/1 时趋近 0。** 它在 y=0.5 时取最大值 0.25,往两端急速衰减:

| 激活值 y | 导数 y(1-y) |
|---|---|
| 0.5 | 0.25(最大) |
| 0.9 | 0.09 |
| 0.99 | 0.0099 |
| 0.9999 | 0.0001 |

std = 1 的直方图恰恰显示激活值大量堆积在 0 和 1 两端——**这些值的导数全都小于 0.01**。

**第三步:链式法则是"连乘"结构,小导数逐层相乘,指数式衰减。** 第 1 层某个权重的梯度,等于顶层传来的梯度依次乘过第 5、4、3、2、1 层的导数因子:

```
第1层的梯度 = 上游梯度 × y₅(1-y₅) × y₄(1-y₄) × y₃(1-y₃) × y₂(1-y₂) × y₁(1-y₁)
```

如果每个因子都像 0.0099 那么小,连乘 5 个就是 0.0099⁵ ≈ 10⁻¹⁰——乘 10 个小于 0.01 的数,任何量级的梯度都会归零,小到 float64 里和 0 没有区别。打个比方:梯度像一场传话游戏,每经过一个饱和神经元,声音就被缩小到百分之一,传过几层后什么也听不见了——底层的权重收到的"该往哪调"的信号几乎为 0,自然学不到东西。

### 用实测数据验证

把脚本换成 5 层 Affine+Sigmoid 网络接 SoftmaxWithLoss(随机 one-hot 标签),反向传播后直接读每层 `Affine.dW` 的标准差:

| 权重初始值 | 第 5 层 dW | 第 1 层 dW | 第 1 层/第 5 层 |
|---|---|---|---|
| std = 1 | 5.2e-02 | 1.2e-02 | 0.23(越靠输入越小) |
| std = 0.01 | 1.3e-04 | 1.0e-10 | 8e-07(急剧消失) |

统计 sigmoid 导数因子本身(std = 1,10 层网络):**每层约 43%~64% 的激活值,其导数因子 y(1-y) < 0.01**,即一半左右的神经元的局部梯度直接被"清零"了——这正是直方图上堆积在两端的那些柱。

### 更完整的图景(两个值得注意的细节)

1. **std = 1 时,整体 dW 的衰减其实比较温和**(10 层网络第 1 层/第 10 层 ≈ 0.28),没有到 10⁻¹⁰ 那么夸张。原因是 `Affine.backward` 的 `dx = dout·Wᵀ` 是矩阵乘法,会把 100 个通道的梯度混合起来,那些少数没饱和的通道仍能传 O(1) 的梯度,把整层的量级撑住。梯度消失更准确地发生在**饱和的那些通道**上:一半以上神经元的梯度被缩小百倍以上,这些连接基本停止学习。而"所有神经元都饱和/输出恒 0 → 整层梯度严格为 0"的剧烈版本,书中实测是在 **ReLU + std = 0.01** 的组合上展示的(激活值全为 0,ReLU 导数恒为 0)。
2. **反直觉的对照:std = 0.01 的 sigmoid 网络梯度消失得反而剧烈得多**(10 层网络第 1 层/第 10 层 ≈ 9e-15)。但它**不是**饱和造成的——实测每层激活值都在 0.5 附近,导数因子恒为最大值 0.25,sigmoid 根本没杀梯度。真正原因是 W 本身太小(~0.01):`Affine.backward` 的 `dx = dout·Wᵀ` 每过一层就把梯度缩小约 0.1 倍,连乘 10 层变成 10⁻¹⁰。可见**梯度消失不止"饱和"一个成因,权重初始值太小同样致命**——这也正是权重初始值问题值得专门研究的原因:Xavier 初始值同时避开这两个坑(激活值不饱和,W 的尺度也不坍缩)。
